## ✏️ Customization Guide

### 1. Update Personal Information

**In `index.html`:**

```html

</div>
```
Change "CMA" to your initials or name.

**Hero Section** (Lines ~61-71):
```html
<h1 class="hero-title">Hi, I'm Christina Martina Afum</h1>
<p class="hero-subtitle">Creative Professional | Designer | Developer</p>
<p class="hero-description">I create beautiful, functional digital experiences that make an impact</p>
```
Update with your name and professional tagline.

**Profile Image** (Line ~83):
```html
<div class="profile-image">CM</div>
```
Change to your initials. To add a photo instead:
```html
<img src="your-image.jpg" alt="Profile" class="profile-image-actual">
```

**About Section** (Lines ~106-120):
Update the paragraph text with your personal story and background.

**Statistics** (Lines ~122-138):
```html
<div class="stat">
    <h3>5+</h3>
    <p>Years Experience</p>
</div>
```
Update numbers and labels to match your achievements.

**Skills Section** (Lines ~146-170):
Edit skill categories and items. To change icons, replace the Font Awesome class:
```html

```
Browse available icons at: https://fontawesome.com/icons

**Portfolio Section** (Lines ~190-240):
Update project information:
```html
<h3>Your Project Title</h3>
<p>Project description here</p>

```

Add more projects by duplicating the `portfolio-card` div.

**Contact Information** (Lines ~256-275):

**Social Links** (Lines ~321-328):

Update URLs to your social media profiles.

## 🐛 Troubleshooting

**Icons not showing?**
- Check internet connection (Font Awesome loads from CDN)
- Verify Font Awesome link is correct in HTML

**Forms not working?**
- Currently shows alert, requires backend service for email delivery
- Consider using Formspree or EmailJS

**Styling looks different?**
- Clear browser cache (Ctrl+Shift+Delete)
- Try in a different browser
- Check that all three files (HTML, CSS, JS) are in same folder

**Mobile menu not working?**
- Ensure JavaScript is enabled
- Check browser console for errors (F12 > Console)
